# Components

This section documents the shared React components used to build consistent FM
Farm experiences. In release **25.0**, the documentation index includes **Table
View** and **Filters View**.

## Choosing a component

- Start with **Table View** in the sidebar when a screen needs to present
  tabular data.
- See **Filters View** in the sidebar for the current documentation status of
  filtering controls.

## Release-specific guidance

These pages describe the documented component behavior for release 25.0. Use
the release selector to compare another published application release. A
component that did not change between releases remains documented in each
release's complete snapshot.

Component implementations and API definitions are maintained outside this
documentation repository. Check the matching component implementation when you
need exact property names, supported interactions, or accessibility behavior;
do not infer those details from a component's name alone.
