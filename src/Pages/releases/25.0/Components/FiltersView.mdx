# Filters View

Filters View is listed as a shared component in the FM Farm UI documentation
for release **25.0**. Its implementation and API are not present in this
repository, so its filtering behavior and configuration cannot be verified
here.

## Before using Filters View

Check the implementation that matches the application release for:

- How filter fields and their available values are configured.
- Which operators and input types are supported.
- How filter changes are applied, cleared, and combined.
- How the component communicates the resulting criteria to its caller.
- Loading, empty, validation, and error behavior.
- Keyboard and screen-reader behavior.

## Documentation status

This page intentionally does not invent a configuration schema or usage
example. Add those once they have been verified against the component
implementation, including a runnable example and its supported options.
