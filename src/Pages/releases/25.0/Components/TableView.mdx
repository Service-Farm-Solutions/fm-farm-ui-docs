# Table View

Table View presents tabular data. Its configuration describes columns, data,
and interactions. The existing component overview says configuration can be
provided as a JavaScript object or in a JSON file.

## Configuration overview

The component implementation and configuration schema are not included in this
documentation repository. Consequently, this page cannot verify the exact
configuration property names, required fields, data types, default behavior, or
supported interactions. Confirm those details against the Table View
implementation before adding a configuration to an application.

When referring to the implementation, document each configuration field with:

- Its exact name, type, and whether it is required.
- Its purpose and default, if one exists.
- A valid value and any relevant constraints.
- The behavior or interaction it controls.

## JavaScript and JSON configuration

Use the configuration format supported by the implementation. A JSON file must
contain valid JSON; a JavaScript configuration may use JavaScript syntax. Do not
copy an illustrative configuration until its fields have been checked against
the installed component version.
