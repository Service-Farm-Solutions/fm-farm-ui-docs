# Modules

This section is the release-specific guide to FM Farm application modules. In
release **25.0**, the documentation index includes **Job Report**.

## Release-specific guidance

Each published release is a complete documentation snapshot for the application
release. A module that did not change remains available in the later snapshot;
its presence does not imply that it changed in that release.

Use the release selector to view a module in another published release. If a
module or page is unavailable in a selected release, switch to a release where
it is documented rather than assuming that a different release's instructions
apply.

## Module documentation

Module implementation and deployment details are maintained outside this
documentation repository. Consult the corresponding release's verified
implementation when exact workflow, permissions, configuration, or data
requirements are needed.
